# Alice OS 12.2 — Fluent/Windows 11 Inspired Icon System

The desktop icon system has been redesigned to replace the old text-symbol icons with smooth local SVG icons.

## Design
- Rounded Fluent/Windows 11-inspired geometry
- Soft gradients and subtle depth
- Consistent 24px SVG viewBox
- Hover lift and glow
- Local assets only; no icon CDN dependency
- Alice logo remains the dedicated Alice OS mark

## Updated areas
- Start menu
- Taskbar pinned apps
- Desktop shortcuts
- Taskbar tray controls
- Top search / assistant / notification controls
- Widget gallery and home customizer
- Weather, system, network and assistant controls

## App icon language
- Files: folder
- Terminal: command prompt
- Settings: gear
- Browser/system tools: clean Fluent-style symbols
- Security: shield/check
- Devices: monitor + device
- Software: download
- Accounts: profile
- Lock: padlock
- Calendar, notes, battery, network, volume, notifications and microphone use matching local SVGs.

The icons are Windows 11-inspired rather than copied proprietary Microsoft artwork, keeping the Alice OS package self-contained and redistributable.
