# UI reference match

The 11.5 desktop is tuned against the supplied Alice OS reference image.

Target characteristics:
- dark blue futuristic wallpaper
- centered Alice Orb + ALICE OS branding
- left desktop icons
- dark glass Start menu anchored bottom-left
- right-side Weather, System Status, Network, and Alice Assistant cards
- full-width dark glass Windows-style taskbar
- compact blue/cyan accents
- responsive mobile fallback

The supplied reference image is treated as a visual target, not as a runtime dependency.
