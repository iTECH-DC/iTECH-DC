# Alice Internet — v12.7

Alice Internet is the system browser shell for Alice OS. DuckDuckGo is the default search engine and Google is available as an explicit option.

## Controls
- Search/address bar: search terms or HTTPS/HTTP URLs
- Engine: DuckDuckGo / Google
- Back / Forward / Reload / Home
- Open externally for sites that block embedded viewing
- Network access follows the Alice OS Network Access switch
- No web history is stored by the browser shell itself

## Security
Alice Internet does not create a general-purpose network proxy. It navigates directly to the requested public URL from the browser context. Network access must be explicitly enabled.

## Shortcut
`Win+B` opens Alice Internet.
