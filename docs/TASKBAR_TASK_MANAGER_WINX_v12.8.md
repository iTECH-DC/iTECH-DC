# Alice OS 12.8 — Taskbar, Task Manager & Power User Menu

## Taskbar
- Start
- Search
- Task View
- Widgets toggle
- Pinned apps and open-window chips
- Network, Bluetooth/devices, Quick Settings and Notifications
- Clock/date calendar panel
- Local taskbar personalization: Search, Task View, Widgets, auto-hide, centered/left alignment
- Right-click taskbar opens the Power User menu

## Task Manager
- Processes with PID, CPU, memory, status and user
- User-owned non-critical process termination with confirmation
- Protected Alice server, PID 1 and critical processes
- Performance view
- Users view
- Details view
- Services inventory (read-only)
- Startup-app/preferences view

## Win+X
Alice provides a Windows-style Power User menu for:
- Installed Apps / Software Center
- Mobility Center / System Control
- Power options
- Event / Action Center
- System settings
- Device Manager
- Network connections
- Disk / Storage Management
- Computer Management / Supervisor
- Task Manager
- Terminal
- Terminal (Admin) entry (host authorization remains required)
- Taskbar settings
- Settings
- Lock
- Shut down / sign out menu

Physical Windows-only functions are represented by Alice-native equivalents where Alice is not the Windows shell. Physical host shutdown/restart and privileged elevation remain controlled by the host OS.
